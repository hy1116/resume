자기소개서

예외 상황을 먼저 짚는 설계와, 직접 실행해 얻은 근거로 판단하는 백엔드 개발자입니다.

1. 견고한 백엔드 설계와 배포 환경 구성

Spring Framework와 Spring Boot를 기반으로 10곳 이상의 쿠폰 공급사 API를 연동했고, 보안 취약점 개선과 시스템 안정화에 힘써 왔습니다. 기능 구현에서 멈추지 않고 Nginx와 Linux 서버를 직접 구성해 배포 환경을 다듬었으며, Jenkins로 빌드부터 배포까지 이어지는 CI/CD 파이프라인을 만들어 배포를 자동화한 경험도 있습니다.

올해는 모바일쿠폰 5개 모듈을 Spring 6·Tomcat 10으로 전환하며 javax에서 jakarta로의 이관과 노후 라이브러리 정리를 마쳤고, 쿠폰함 어드민을 Kubernetes로 배포했습니다. 핀 발급과 고객사 API 호출 통계도 직접 구축해, 연동 장애가 생기면 어느 공급사·고객사·API에서 났는지 바로 파악할 수 있게 했습니다.

2. 대량 트래픽 처리와 성능 최적화

매달 정해진 시간에 선착순 쿠폰 발행 이벤트를 여는 스타드림(KB국민카드) 서비스를 운영하며, 이벤트가 시작될 때마다 사용자가 한꺼번에 몰려 생기는 트래픽 폭주와 성능 병목을 여러 차례 해결했습니다. 병목 구간을 분석해 인덱스를 추가하고 쿼리를 튜닝했으며, DB 커넥션 풀 크기를 조정해 동시 접속 처리 한계를 끌어올렸습니다.

당첨자 추첨처럼 즉시 처리하지 않아도 되는 로직은 배치로 분리해 부하를 시간대별로 나눴고, 이벤트 시간대의 순간 부하에 대비해 서버 자원도 미리 늘렸습니다. 이후 약 3년간 이벤트를 안정적으로 운영하면서, 트래픽이 순간적으로 몰리는 상황을 어떻게 진단하고 대응해야 하는지 몸으로 익혔습니다. 대량 발송에서도 같은 방식으로 로직과 쿼리를 개선해 2,000건 발송 시간을 약 1시간에서 약 5분으로 줄였습니다.

3. 협업과 성장을 지향하는 태도

KB국민카드, SC제일은행, 로레알몰, S-OIL 등 성격이 다른 10곳 이상의 고객사 프로젝트를 진행하며, 저마다 다른 요구사항과 일정에 맞춰 이해관계자와 소통하고 조율하는 힘을 길렀습니다. CMS 개선이나 대량발송 속도 개선처럼 지시받은 일이 아니라 운영 중에 직접 발견한 문제를 팀장님과 운영팀에 제안해 개선까지 이끈 경험도 여러 번 있습니다.

협업 속에서 문제를 찾고 풀어 가는 과정에 보람을 느낍니다. 최근에는 StockSense·APIverse 같은 개인 프로젝트로 FastAPI, Kubernetes, AI 예측 모델처럼 실무에서 다뤄 보지 못한 영역을 직접 구현하며 역량을 넓히고 있습니다.

4. 차별화된 강점: 여러 각도에서 예외를 먼저 짚는 설계

설계 단계에서 기능 구현에 그치지 않고, 일어날 수 있는 예외 상황을 여러 각도에서 따져 보는 것이 저의 가장 큰 강점입니다. 쉽게 지나칠 수 있는 로직의 빈틈을 미리 짚어 방어 코드를 설계하고, 장애 가능성을 사전에 막는 데 집중합니다. 통계를 저장하다 실패해도 핀 발급과 API 응답에는 영향이 가지 않게 분리하는 식의 판단이 이런 습관에서 나옵니다.

다만 세부 사항에 깊이 몰입하다 보니 시간이 오래 걸리는 편이었는데, 최근에는 반복적인 검증 작업에 AI 도구를 적극 활용해 이를 보완하고 있습니다. 분석의 정밀함은 유지하면서 작업 속도를 높이고, 그렇게 아낀 시간을 설계와 문제 해결에 쓰고 있습니다.

5. 가치관: 실행으로 얻는 데이터의 가치

'경험하지 못한 것에 대한 후회보다, 실행해서 얻은 데이터가 더 값지다'는 신념을 가지고 있습니다. 실패는 단순한 실수가 아니라 다음 결정을 더 정교하게 만드는 가장 확실한 지표라고 믿기 때문입니다.

이 가치관은 일하는 방식으로도 이어집니다. 설계나 로직에 의문이 생기면 이론에 머물지 않고 개인 프로젝트로 직접 구현해 가설을 검증하고, 그 과정에서 부딪힌 문제를 풀며 기술의 장단점과 업계 관행이 자리 잡은 이유를 체득해 왔습니다. 이렇게 직접 겪으며 얻은 근거를 바탕으로, 언제나 이유 있는 설계를 제시하는 개발자가 되겠습니다.
